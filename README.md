# Spike Run Game

A browser-based spike run game built with HTML5 Canvas and JavaScript.

## Play Online

[Live Demo on Vercel](https://your-domain.vercel.app)

## Local Development

Simply open `index.html` in your browser to play locally.

## Deploy

This game is deployed on Vercel. To deploy your own version:

1. Fork or clone this repository
2. Sign up at [vercel.com](https://vercel.com)
3. Import the project
4. Deploy!

## Game Controls

- **Space** or **Click** to jump
- Avoid the spikes
- Survive as long as you can!
